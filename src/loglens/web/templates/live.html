Remote server forwarding

Pipe live streams from your VPS, Docker Compose containers, or control panels into LogLens

POST /api/ingest/stream
Manual CLI alternative (optional)
Prefer running commands from your terminal instead of the built-in Remote VPS (SSH stream) form above? You can pipe live streams directly into LogLens over HTTP: 
ssh root@<YOUR_VPS> "<remote_tail_cmd>" | curl -s -X POST http://localhost:8080/api/ingest/stream -H "X-Log-Source: <source>" -T -
Pelican panel (Docker Compose)
~/pelican-panel

Run inside your Pelican directory (cd ~/pelican-panel) to forward live logs:

Pelican app stream: 
cd ~/pelican-panel && docker compose logs -f --tail=50 app | curl -s -X POST http://<YOUR_IP>:8080/api/ingest/stream -H "X-Log-Source: pelican-panel" -T -
Laravel error log file: 
cd ~/pelican-panel && docker compose exec -T app tail -F storage/logs/laravel-$(date +%Y-%m-%d).log | curl -s -X POST http://<YOUR_IP>:8080/api/ingest/stream -H "X-Log-Source: pelican-panel" -T -
Caddy web server logs: 
cd ~/pelican-panel && docker compose logs -f --tail=50 caddy | curl -s -X POST http://<YOUR_IP>:8080/api/ingest/stream -H "X-Log-Source: pelican-caddy" -T -
CyberPanel (OpenLiteSpeed & Sites)
Port 8090 / OLS

Forward web server, virtual hosts, and ModSecurity WAF block logs:

OpenLiteSpeed global access log: 
tail -F /usr/local/lsws/logs/access.log | curl -s -X POST http://<YOUR_IP>:8080/api/ingest/stream -H "X-Log-Source: cyberpanel-ols" -T -
All hosted websites access logs: 
tail -F /home/*/logs/*.access_log | curl -s -X POST http://<YOUR_IP>:8080/api/ingest/stream -H "X-Log-Source: cyberpanel-sites" -T -
OpenLiteSpeed errors & WAF blocks: 
tail -F /usr/local/lsws/logs/error.log | curl -s -X POST http://<YOUR_IP>:8080/api/ingest/stream -H "X-Log-Source: cyberpanel-waf" -T -
