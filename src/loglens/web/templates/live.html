Remote server forwarding

Pipe logs from external VPS hosts, containers, or game panels into LogLens via HTTP

POST /api/ingest/stream
Pterodactyl & Pelican panel logs

Pipe panel logs in real time from your game server VPS: 

tail -F /var/www/pterodactyl/storage/logs/laravel-$(date +%Y-%m-%d).log | curl -s -X POST http://<HOST>:8080/api/ingest/stream -H "X-Log-Source: pterodactyl-panel" -T -
Or for Pelican / Wings Docker daemon: 
docker logs -f pterodactyl-wings | curl -s -X POST http://<HOST>:8080/api/ingest/stream -H "X-Log-Source: pterodactyl-wings" -T -
Linux SSH & web access logs

Forward SSH auth failures or web proxy access logs: 

tail -F /var/log/auth.log | curl -s -X POST http://<HOST>:8080/api/ingest/stream -H "X-Log-Source: vps-auth.log" -T -
For Nginx or reverse proxy logs: 
tail -F /var/log/nginx/access.log | curl -s -X POST http://<HOST>:8080/api/ingest/stream -H "X-Log-Source: nginx-access.log" -T -
