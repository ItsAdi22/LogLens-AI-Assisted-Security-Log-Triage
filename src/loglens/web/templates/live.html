🌐 Connect Remote Servers & VPS Panels

If your game servers, Pterodactyl, or Pelican VPS runs on a separate machine, pipe logs directly into LogLens over HTTP using this live ingestion endpoint:

Ingestion Endpoint: POST /api/ingest/stream
🎮 Pterodactyl & Pelican Game Panel Logs

Run this in your VPS terminal to continuously pipe panel logs to LogLens in real-time: 

tail -F /var/www/pterodactyl/storage/logs/laravel-$(date +%Y-%m-%d).log | curl -s -X POST http://<YOUR_IP>:8080/api/ingest/stream -H "X-Log-Source: pterodactyl-panel" -T -
Or for Pelican / Wings Docker daemon: 
docker logs -f pterodactyl-wings | curl -s -X POST http://<YOUR_IP>:8080/api/ingest/stream -H "X-Log-Source: pterodactyl-wings" -T -
🐧 Linux SSH & Nginx Web Logs

Forward SSH auth failures or web proxy access logs directly from any remote Linux server: 

tail -F /var/log/auth.log | curl -s -X POST http://<YOUR_IP>:8080/api/ingest/stream -H "X-Log-Source: vps-auth.log" -T -
For Nginx or Caddy web server logs: 
tail -F /var/log/nginx/access.log | curl -s -X POST http://<YOUR_IP>:8080/api/ingest/stream -H "X-Log-Source: nginx-access.log" -T -
