Remote server forwarding

Pipe live streams from your VPS, Docker Compose containers, or game panels into LogLens

POST /api/ingest/stream
Pelican panel (Docker Compose)
~/pelican-panel

Run inside your Pelican directory (cd ~/pelican-panel) to forward live logs:

Pelican app stream: 
cd ~/pelican-panel && docker compose logs -f --tail=50 app | curl -s -X POST http://<YOUR_IP>:8080/api/ingest/stream -H "X-Log-Source: pelican-panel" -T -
Laravel error log file: 
cd ~/pelican-panel && docker compose exec -T app tail -F storage/logs/laravel-$(date +%Y-%m-%d).log | curl -s -X POST http://<YOUR_IP>:8080/api/ingest/stream -H "X-Log-Source: pelican-panel" -T -
Caddy web server logs: 
cd ~/pelican-panel && docker compose logs -f --tail=50 caddy | curl -s -X POST http://<YOUR_IP>:8080/api/ingest/stream -H "X-Log-Source: pelican-caddy" -T -
Wings daemon & Linux servers
Host & Daemons

Forward game node daemons or Linux system authentication logs:

Wings game server daemon: 
docker logs -f --tail=50 wings | curl -s -X POST http://<YOUR_IP>:8080/api/ingest/stream -H "X-Log-Source: pelican-wings" -T -
Linux SSH auth failures: 
tail -F /var/log/auth.log | curl -s -X POST http://<YOUR_IP>:8080/api/ingest/stream -H "X-Log-Source: vps-auth.log" -T -
Traditional /var/www/pterodactyl: 
tail -F /var/www/pterodactyl/storage/logs/laravel-$(date +%Y-%m-%d).log | curl -s -X POST http://<YOUR_IP>:8080/api/ingest/stream -H "X-Log-Source: pterodactyl-panel" -T -
